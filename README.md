# SHIBUYA RUSH

ハチ公前から、大混雑の渋谷を最速で目的地まで走り抜ける3Dゲーム(Unity 6000.4.4f1 / URP)。
街は実際の渋谷のデータから生成します。道路はOSM、建物の高さはPLATEAU、標高は国土地理院DEM。道という道を3万人規模の人混みが歩いています。

## 遊ぶ
`Build/ShibuyaRush.app` を開く(未ビルドなら下の「ビルド」)。メニューで目的地を選ぶ(タップ・クリック、または1〜6キー)。

| 操作 | PC | スマホ |
|---|---|---|
| 走る | 画面をドラッグ(押した所が中心。マウスでも同じ)、または WASD | 画面の左側をドラッグ(仮想スティック) |
| 視点 | 自動で進行方向に追従。右ドラッグ・←→で手動 | 画面の右側を横スワイプ |
| ダッシュ | Shift か 円ボタン(雷) | 右下の円ボタン(雷) |
| すり抜け | Space か 円ボタン(おばけ) | 右下の円ボタン(おばけ) |
| かき分け | E か 円ボタン(爆発) | 右下の円ボタン(爆発) |
| 結果画面 | R もう一度 / M 目的地選択(ボタンもタップ可) | ボタンをタップ |

目的地は OSM の実在地点: メガドンキ、SHIBUYA TSUTAYA、TSUTAYA(東口側)、スクランブルスクエア、ヒカリエ、マークシティ。

障害物はすべて硬いです。建物の壁、車(止まっていても)、人にぶつかると押し戻され、人には弾かれてよろけます。ダッシュは人を弾き飛ばして突き進み、すり抜けは人と車を貫通し、かき分けは前方を吹き飛ばします。建物の中を通れるのは、駅構内などの歩行者通路(中心線から1.6m以内)と、高架の下だけです。
画面上部の大きな矢印と、プレイヤーの前に浮かぶ3D矢印が、常に目的地の方向を指します。

スキルを使うと、スローモーション(すり抜け)、時計の一時停止(TIME STOP)、ヒットストップ、カメラの揺れとズーム、衝撃波、残像、火花、色収差・ブルーム・周辺減光、スピード線、効果音(コードで生成)が入ります。

ハイパーカジュアル系ゲームを参考にした作りです。
- 見た目: 丸みのあるデフォルメ人形、夕方の光と空、パステルの街、夕暮れに光る窓、横断歩道の白線。
- コンボ: 突進・かき分けで人を弾き飛ばすと増える。25ごとに時計が1秒戻る(NICE! / GREAT! / AMAZING! / UNSTOPPABLE!)。
- ★評価: 直線距離から決めた基準時間で★3(0.19秒/m+5秒以内)・★2(0.30秒/m+9秒以内)・★1。メニューに最高の★とベストタイムを保存。
- 手触り: ぶつかると人形がつぶれる、人が宙で回転しながら飛ぶ、ダッシュ中のカメラの広がりと傾き、足元の目印リング、ゴールの紙吹雪。
- 音: BGMと効果音はすべてコードで生成。コンボが増えるほど「ポップ音」の音程が上がる。すり抜け中はBGMのピッチが下がる。

建物の中には入れず、道に限らず建物の隙間は通れます。

## スマホ対応
- タッチ操作(仮想スティック・右側スワイプ・円ボタン)、縦画面・横画面、ノッチ(セーフエリア)に対応。画面の短辺を基準にUIを拡縮し、スマホでは文字やボタンを大きくする。
- スマホでは人6,000人・車150台、影と描画距離を絞り、解像度を85%にする軽量設定になる(`-crowd N` `-cars N` で変更可)。
- デスクトップでも `-mobile` を付けるとタッチUIで起動できる(例: `-screen-width 844 -screen-height 390 -mobile`)。
- iOS: `ProjectSetup.BuildIOS` がXcodeプロジェクトを出力する(`Build/iOS`、署名とApp Storeへの提出はXcodeで行う)。`-simulator` を付けるとiOSシミュレーター用になる。Androidのビルドモジュールはこの環境に入っていないため未確認。

## 街
- 小物: ハチ公像(スタート地点の隣。OSMの位置ではなく原点に置いている)、街路樹(OSMの172本+大通りの歩道沿いに補う)、街灯、歩行者用信号(青赤が実際に切り替わる。青のときだけ車が止まる)、道に面した壁のネオン看板。
- 建物の外壁は窓つき(テクスチャ。夕方は窓が光る)。高さはPLATEAU。横断歩道は白いしま模様で描く。
- 高架: OSMの bridge / layer から、歩道橋・駅のデッキ・首都高(高さ5.2m×layer、首都高は10.4m)を持ち上げて描く。両端は地面から滑らかに上り、18mおきに柱を立てる。階段は両端の高さをつなぐ斜面。人混みの約5%とプレイヤーは高架の上も歩ける。
- 車: 800台が左側通行で走る。信号つき横断歩道の近くでは歩行者青の間止まり、それ以外の交差点では東西・南北を交互に通す。前の車と、前方の歩行者を避けて止まる。走行中の車(時速7km超)に当たると +3秒 と弾き飛ばし。止まっている車は通り抜けられる。
- 歩行者は、車道では道の両端(歩道側)を歩く。

## 人混み
- 各人が約300か所のハブ(目的地)から1つを選び、道路グラフ上の最短経路で歩く。着いたら別のハブを選び直し、永遠に続く。
- 既定は50,000人と車800台(`-crowd N` `-cars N` で変更)。M4 Proで約84fps(Botでの実測、1280x720、6か所の目的地で約79〜82fps)。遠くの人は3フレームに1回だけ動かして負荷を抑えている。
- 信号つき横断歩道(OSMのcrossing=traffic_signals、91本)では、赤の間は手前で待ち、青で一斉に渡る(周期90秒、青38秒。80m四方の格子ごとに位相をそろえている)。車は走っていない。
- 近くは関節つきの人形(胴・頭・両腕・両脚が歩行位相で振れる)、遠くは簡易形状。GPUインスタンシングで描画。

## 作り直す
```bash
python3 tools/fetch_osm.py     # Overpass から取得(data/raw)
pip3 install mapbox-vector-tile && python3 tools/fetch_plateau.py   # PLATEAUの建物高さ(data/raw/plateau.json)
python3 tools/build_terrain.py # 国土地理院DEMから game/Assets/Resources/terrain.bytes を生成
python3 tools/build_city.py    # game/Assets/Resources/city.json を生成(ハチ公像が原点、x=東 z=北 [m])
# ビルド(約1〜2分)
/Applications/Unity/Hub/Editor/6000.4.4f1/Unity.app/Contents/MacOS/Unity -batchmode -quit \
  -projectPath game -executeMethod ProjectSetup.BuildMac -logFile build.log
```

## 自動プレイ(検証用Bot)
```bash
tools/run_bot.sh <目的地0-5> <出力名> [-crowd N] [-cars N] [-noskills] [-start x z] [-selftest] [-fxtest]   # Shots/<出力名>/ にスクショとresult.json
```
Botは道路グラフのA*で目的地に向かい、詰まるとダッシュ・すり抜け・かき分けを使います。直接起動するとウィンドウが隠れて止まることがあるため、スクリプトは `open` で前面に出して起動します。

## 自動検証
- `-selftest`: 建物の壁(約180か所)へ向かって走ってめり込む件数と、止めた人(約130人)へ走って近づきすぎる件数を数える。壁は0件。人は2件で、どちらも壁と人の間に挟まれた例。
- Botの経路: 道路グラフのA*。建物の中を通ってしまう車道の辺(22本)は取り除く。ゴールは地上のノードにする(高架の上は階段を探さないと着けないため)。

## 検証の記録(Botでの自動プレイ、5万人)
- 6か所の目的地すべてに到着。所要は13〜44秒、約73〜81fps(M4 Pro、1280x720)。
- スキルなしだとメガドンキまで115.7秒、スキルありは33.5秒。障害物が硬いので、スキルなしでは大きく遅れる。
- 演出の確認: `tools/run_bot.sh 3 fx -fxtest -quitafter 30` で3つのスキルを順に発動し、`Shots/fx/` にスクリーンショットを出す。
- スマホ画面の確認: `-mobile -fakejoy -screen-width 844 -screen-height 390`(横)、`390 844`(縦)で撮る。

## 既知の制約
- 標高は4m格子。地下(地下街・地下鉄)は再現していない。高架はOSMにあるものだけで、駅ビルの内部通路は無い。
- 建物は輪郭を高さで押し出した箱。使っているMVT(indigo-lab配信)には輪郭と高さしかなく、屋根の形などPLATEAU LOD2の形状は入っていない(形状まで使うにはCityGML/3D Tilesの取得が必要)。
- 信号を守る義務はプレイヤーにはない(車に当たると+3秒)。車の種類はセダン1種類のみ。
- 人どうしの当たりは簡易的な押し合いのみ。
